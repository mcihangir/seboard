NXP NFC Reader Antenna Design tools

NXP-NFC-Reader Antenna Tuning.xls
MS Excelsheet to execute an NXP NFC Reader antenna tuning. It allows to create a simple netlist for the simulation with RFSIM99.

NXP-NFC-Reader-DPC-LUT-Calibration.xlsx
MS Excelsheet to execute the accurate DPC calibration for the PN5190 and derivatives. It requires to set the VDDPA and the distance with the EMVCo TestPICC to achieve the required power transfer, read the related current and enter it into the sheet. The sheet indicates "bad" values, and creates a current reduction look up table, which then needs to be manually entered into the NFC controller EEPROM.

NXP-NFC-Reader-LUT_based_Shaping_Tool.xlsx
MS Excelsheet to support the LUT based Tx shaping feature of the PN5190 and derivatives. It allows to analyse (visualize) rise and fall behavior based on given registers or create a smooth shape based on an e-function.

NXP-NFC-Reader-DPR.xlsx
MS Excelsheet to evaluate and visualize the effect of dynamic power regulation (DPR).
